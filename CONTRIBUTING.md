# Contributing

Bug reports are welcome. This project intentionally has a very narrow scope: restoring the broken Thermal Expansion Kit Assembler recipe in Energy Control 1.12.2-0.3.2.

## Bug reports

Please include exact mod versions, reproduction steps, and `latest.log` or the relevant crash report.

## Pull requests

Changes should remain focused on the documented recipe compatibility problem or direct regressions caused by this patch.

All contributed code must be compatible with the project's GPL-3.0 license.
